# Octet 0.4.0

Released 2026-11-11. Rolls up 0.3.0 through 0.3.6; the code is 0.3.6's.

## New

- **`/mcp`** opens an MCP servers dialog for the thread's running agent: each server's status
  (connected, connecting, failed with its error, needs sign-in, disabled), where it is
  configured, its tools, and a remote server's origin, kept live while the dialog is open.
  Claude servers can be reconnected and enabled or disabled; Codex servers can be signed into
  in the browser, and Codex's MCP config reloaded.
- **MCP service logos** on tool calls in the timeline: the Swift Octet's 47 marks plus 52 more
  from Simple Icons, and the site favicon for 16 services Simple Icons lacks. Works with
  Claude's `mcp__server__tool` and Codex's `server.tool` names.
- **Overview agent tree**: agents nested with the scripts, monitors and tasks they started;
  only live work leads, and finished agents fold into a collapsed Finished group.
- **Lineage** in thread details shows the same tree, agents only and one line per agent, with
  running shells, monitors and tasks in their own **Shells & monitors** section.
- **Hold Space to dictate**, with the composer folding into a recording view and a live
  waveform; the transcript so far replaces the hint.
- **Tasks card** in thread details, with a staggered entrance; activity hints (agent avatars,
  command counts, TODO count, PR/check status) on the surface launcher and `+` menu.
- **`octet pair`** replaces `t3 pair`, and the `octet` CLI installs on your PATH.
- A blue glow marks `!` shell prompts in the composer.

## Improved

- The sidebar usage card: plan on its own line, one block per limit, full-width bars.
- Open collapsible group headers (sidebar shelves, Todos, Tasks, Finished) get a selected
  background.
- Project icons are found in an app's own Xcode targets at the project root, through
  page-relative favicon links, and in monorepo `apps/*` and `packages/*`.
- One centred empty state across panels; the conversation-width grip no longer covers the
  message navigation marks.

## Fixed

- **Stop all** no longer shows on idle threads: work left marked running by a run that ended
  is ignored.
- An agent tab whose thread switched providers no longer overlaps its title with a second icon.
- The voice waveform no longer clips on a one-line composer.
- The last Lineage branch's line meets its curve without a stub.
- Docker and other container runtimes' ports are no longer credited to the thread that started
  them.

## Removed

- **Chrome DevTools**: no Toggle Developer Tools item or ⌥⌘I, no DevTools in development runs,
  no Open DevTools in the browser preview. DevTools is off on the app's windows,
  remote-debugging switches are stripped at startup, and the packaged app ignores `--inspect`.
- **Two-finger swipe** back and forward, both the in-app trackpad gesture and the macOS swipe.
  The sidebar's back and forward buttons remain.

## Known limits

- Claude's SDK has no MCP sign-in; `/mcp` points claude.ai connectors to claude.ai and other
  servers to `claude` → `/mcp` in a terminal.
- Helper processes Octet runs through its own binary as Node can still be started with
  `--inspect`; turning that off would stop the helpers.
- The build is ad-hoc signed, not notarized.
